# Rivet – Electron SFTP/WebDAV 文件浏览器

> **项目代号**：Rivet  
> **技术栈**：Electron + React + TypeScript + TailwindCSS  
> **目标**：提供跨平台的多协议远程文件管理工具，第一版（v1.0）聚焦核心文件操作与多会话管理，同时架构可扩展。  
> **文档用途**：供 AI IDE（如 Trae）直接生成代码。本文档采用**契约式设计**，包含类型定义、接口签名、组件结构、状态管理设计，尽可能减少自然语言歧义。

### 1.1 包含功能

| 模块       | 功能列表                                                                                                 |
| ---------- | -------------------------------------------------------------------------------------------------------- |
| 连接管理   | SFTP/WebDAV 连接（主机、端口、用户名、密码或私钥），保存/删除连接，密码/私钥使用系统凭据管理器（keytar） |

## 4. 核心类型定义（`shared/types.ts`）

```typescript
// 连接配置（存储时不包含密码/私钥原文）
export interface ConnectionConfig {
  id: string; // UUID
  name: string; // 用户自定义显示名
  protocol: "sftp" | "webdav";
  host: string;
  port: number;
  username: string;
  credentialId: string; // 对应 keytar 中的键
  // 可选：私钥路径（SFTP）等扩展字段
}

// 文件信息（从协议返回）
export interface FileInfo {
  name: string;
  type: "file" | "directory";
  size: number; // 字节
  modifyTime: number; // Unix 时间戳
}

// 传输任务（队列用）
export interface TransferTask {
  id: string;
  sessionId: string;
  type: "upload" | "download";
  localPath: string;
  remotePath: string;
  status: "pending" | "active" | "completed" | "failed";
  progress: number; // 0-100
  error?: string;
}

// UI 设置存储结构
export interface UiSettings {
  theme: "light" | "dark" | "system";
  language: "zh-CN" | "en-US";
  sidebarWidth: number;
  queueDrawerOpen: boolean;
  queueDrawerWidth: number;
}

// 主进程预加载暴露的 API 类型
export interface ElectronAPI {
  // 会话
  connect(
    config: Omit<ConnectionConfig, "id" | "credentialId"> & {
      password?: string;
      privateKey?: string;
    },
  ): Promise<string>;
  disconnect(sessionId: string): Promise<void>;
  listDirectory(sessionId: string, path: string): Promise<FileInfo[]>;
  createDirectory(sessionId: string, path: string): Promise<void>;
  rename(sessionId: string, oldPath: string, newPath: string): Promise<void>;
  delete(sessionId: string, path: string): Promise<void>;
  uploadFile(
    sessionId: string,
    localPath: string,
    remotePath: string,
    signal?: AbortSignal,
  ): Promise<void>;
  downloadFile(
    sessionId: string,
    remotePath: string,
    localPath: string,
    signal?: AbortSignal,
  ): Promise<void>;
  cancelTransfer(transferId: string): Promise<void>; // 取消进行中的传输

  // 存储
  storeGet(key: string): unknown;
  storeSet(key: string, value: unknown): void;
  storeDelete(key: string): void;

  // 事件监听
  onProgress(callback: (event: ProgressEvent) => void): () => void;
}

export interface ProgressEvent {
  transferId: string;
  sessionId: string;
  operation: "upload" | "download";
  path: string;
  percent: number;
}

declare global {
  interface Window {
    electronAPI: ElectronAPI;
  }
}
```

## 5. 主进程设计（TypeScript）

### 5.1 协议抽象（`BaseProtocol.ts`）

```typescript
export interface FileProtocol {
  connect(config: any): Promise<string>; // 返回 session handle
  disconnect(sessionId: string): Promise<void>;
  list(sessionId: string, path: string): Promise<FileInfo[]>;
  uploadFile(
    sessionId: string,
    localPath: string,
    remotePath: string,
    onProgress: (percent: number) => void,
    signal?: AbortSignal,
  ): Promise<void>;
  downloadFile(
    sessionId: string,
    remotePath: string,
    localPath: string,
    onProgress: (percent: number) => void,
    signal?: AbortSignal,
  ): Promise<void>;
  mkdir(sessionId: string, path: string): Promise<void>;
  rename(sessionId: string, oldPath: string, newPath: string): Promise<void>;
  delete(sessionId: string, path: string): Promise<void>;
}
```

SftpProtocol 和 WebdavProtocol 实现该接口。  
协议工厂根据 `protocol` 字符串返回对应的类实例。

### 5.2 IPC 处理器（`ipcHandlers.ts`）

注册所有 `electronAPI` 对应的方法。  
对于上传/下载，维护 `Map<transferId, AbortController>` 以支持取消。

## 6. 渲染进程设计

### 6.1 状态管理（Zustand 切片）

**sessionStore.ts**  
管理会话列表、当前激活会话、每个会话的当前路径和文件列表。  
类型：

```typescript
interface Session {
  id: string;
  config: ConnectionConfig; // 仅包含元信息，无密码
  currentPath: string;
  files: FileInfo[];
}

interface SessionStore {
  sessions: Session[];
  activeSessionId: string | null;
  addSession: (
    config: ConnectionConfig,
    password?: string,
    privateKey?: string,
  ) => Promise<void>;
  removeSession: (id: string) => void;
  setActiveSession: (id: string) => void;
  updateCurrentPath: (sessionId: string, path: string) => void;
  setFiles: (sessionId: string, files: FileInfo[]) => void;
  refreshCurrentDirectory: (sessionId: string) => Promise<void>;
}
```

**queueStore.ts**  
管理传输任务列表，并发控制（v1.0 硬编码最大 3）。  
提供 `addTask`, `cancelTask`, `updateTaskProgress`, `completeTask`, `failTask` 等方法。  
调度逻辑放在自定义 Hook `useTransferQueue` 中。

**uiStore.ts**  
存储 UI 设置（主题、语言、侧边栏宽度、队列面板状态）。  
持久化使用 `electronStore`（通过 `electronAPI.storeSet/Get`），初始化时读取。

### 6.2 主题系统

- CSS 变量定义在 `:root` 和 `[data-theme="dark"]` 中。
- 亮色/暗色配色借鉴 VSCode 的 **Light+** 和 **Dark+** 主题。
- 使用 `useTheme` Hook：
  - 监听 `uiStore.theme`，若为 `system` 则使用 `matchMedia` 监听系统变化。
  - 设置 `document.documentElement.dataset.theme` 为 `'light'` 或 `'dark'`。
- 主题切换按钮：循环切换 `light` → `dark` → `system` → `light`。

### 6.3 国际化

- `i18n/index.ts` 初始化 `i18next`，配置资源加载器（静态导入 json）。
- 语言检测顺序：`uiStore.language`（用户选择） → 系统语言（`navigator.language` 匹配 `zh-CN` 或 `en-US`，否则 `en-US`）。
- 切换语言：`i18n.changeLanguage(lang)` 并保存到 store。
- 所有组件使用 `useTranslation()`。

### 6.4 液态玻璃弹窗（blur 效果）

所有 Dialog 组件（`ConnectionDialog`, `ConfirmDialog`）使用以下样式类：

```css
.glass-dialog {
  @apply fixed inset-0 flex items-center justify-center bg-black/30 backdrop-blur-md z-50;
}
.dialog-content {
  @apply bg-white/90 dark:bg-gray-800/90 rounded-lg shadow-xl p-6 min-w-[400px] border border-white/20 dark:border-gray-700/50;
}
```

### 6.5 快捷键

在 `App.tsx` 中监听 `window` 的 `keydown` 事件：

- `F5`：调用当前会话的刷新（`sessionStore.refreshCurrentDirectory`）
- `Delete`：删除当前选中的文件（需维护 `selectedFile` 状态，由文件列表组件管理）

## 8. IPC 通信详细规范

所有调用均使用 `window.electronAPI`。  
进度监听：

```typescript
useEffect(() => {
  const unsubscribe = window.electronAPI.onProgress((event) => {
    queueStore.updateTaskProgress(event.transferId, event.percent);
  });
  return unsubscribe;
}, []);
```

取消上传/下载：  
当用户取消任务时，调用 `window.electronAPI.cancelTransfer(transferId)`，主进程通过 `AbortController.abort()` 中止传输，并在完成后发送错误进度事件。

## 9. 配置存储（electron-store）

预加载暴露 `storeGet`, `storeSet`, `storeDelete`。  
存储的键：

- `saved_connections`: `ConnectionConfig[]`（不含密码）
- `ui_settings`: `UiSettings`
- 注意：密码/私钥使用 `keytar` 存储，键为 `connection_<credentialId>`。

初始化时，如果 `ui_settings` 不存在，则创建：

```typescript
const defaultUi: UiSettings = {
  theme: "system",
  language: "system", // 实际解析为 zh-CN 或 en-US
  sidebarWidth: 260,
  queueDrawerOpen: false,
  queueDrawerWidth: 360,
};
```

程序启动时，读取存储并初始化 Zustand stores。

## 10. 构建与打包（TypeScript 配置要点）

- 主进程：`tsconfig.json` 设置 `"module": "CommonJS"`，`"target": "ES2020"`。
- 渲染进程：使用 Vite 的 React + TypeScript 插件，输出到 `dist/renderer`。
- 在 `package.json` 中指定 `"main": "dist/main/main.js"`。
- 使用 `electron-builder` 打包，需要 `electron-rebuild` 处理 `ssh2` 原生模块。
