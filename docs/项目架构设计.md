# Rivet – Electron SFTP/WebDAV 文件浏览器

> **项目代号**：Rivet  
> **技术栈**：Electron 42 + React 19 + TypeScript + TailwindCSS 4  
> **版本**：v0.0.1  
> **目标**：提供跨平台的多协议远程文件管理工具，聚焦核心文件操作与多会话管理。

---

## 1. 功能范围（v0.0.1 已实现）

### 1.1 已实现功能

```typescript
export interface ConnectionConfig {
  connectionUuid: string // 连接唯一标识
  name: string // 用户自定义显示名
  protocol: ProtocolType // 协议类型
  host: string // 主机地址
  port: number // 端口
  username: string // 用户名
  password?: string // 密码（运行时使用，不存储）
  savePassword?: boolean // 是否保存密码
  basePath?: string // 基础路径（WebDAV）
  scheme?: 'http' | 'https' // WebDAV 协议类型
  rejectUnauthorized?: boolean // 是否验证 SSL 证书
}

export type ConnectionConfigWithoutPassword = Omit<ConnectionConfig, 'password'>
```

## 5. 主进程架构

### 5.1 协议抽象层

**`FileProtocol` 接口**（`main/services/protocol/base.ts`）：

```typescript
export interface FileProtocol {
  readonly protocolType: ProtocolType
  connect(config: ConnectionConfig): Promise<OperationResult>
  disconnect(sessionId: string): Promise<void>
  list(sessionId: string, path: string): Promise<FileInfo[]>
  mkdir(sessionId: string, path: string): Promise<void>
  rename(sessionId: string, file: FileInfo, newName: string): Promise<void>
  delete(sessionId: string, file: FileInfo): Promise<void>
  copy(sessionId: string, file: FileInfo, targetPath: string): Promise<void>
  move(sessionId: string, file: FileInfo, targetPath: string): Promise<void>
  ping(sessionId: string): Promise<void>
}
```

**`BaseProtocolImpl` 抽象基类**：提供通用辅助方法。

```typescript
export abstract class BaseProtocolImpl<T> {
  abstract readonly protocolType: ProtocolType

  protected getClient(sessionId: string): T
  protected calculateProgress(transferred: number, totalSize: number): number
  protected setupAbortHandler(signal?: AbortSignal): {
    getAborted: () => boolean
    cleanup: () => void
  }
  protected logOperation(operation: string, source: string, target: string, error?: unknown): void
}
```

**协议实现类**：

| 类               | 文件        | 说明                                      |
| ---------------- | ----------- | ----------------------------------------- |
| `SftpProtocol`   | `sftp.ts`   | SFTP 协议实现，支持密码认证和主机密钥验证 |
| `WebdavProtocol` | `webdav.ts` | WebDAV 协议实现，支持 HTTP/HTTPS          |

### 5.2 会话管理

**`SessionManager`**（`main/services/session-manager.ts`）：单例服务，管理所有会话连接。

### 5.3 SSH 主机密钥验证

SFTP 连接时的主机密钥验证流程：

1. **首次连接**：显示主机密钥指纹，用户确认后保存到 `known_hosts`
2. **密钥匹配**：正常连接
3. **密钥不匹配**：显示警告对话框，阻止连接

- 使用 CSS 变量定义主题色
- `useTheme` Hook 监听主题变化

### 6.4 国际化

- 支持语言：中文（`zh-CN`）、英文（`en-US`）
- 语言资源文件：`renderer/i18n/locales/`

## 7. 安全设计

### 7.1 密码存储

- 使用 `keytar` 将密码存储到系统凭据管理器
- 存储键：`connection_<connectionUuid>`
- 连接配置中不包含密码明文

### 7.2 SSH 主机密钥验证

- 首次连接时验证主机密钥指纹
- 密钥变更时阻止连接并警告用户
- 已知主机密钥存储在 `electron-store` 的 `known_hosts`

### 7.3 IPC 安全

- 启用 contextIsolation
- API 白名单机制
- 参数类型校验
