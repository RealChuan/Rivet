## 1. 项目概述

### 1.1 项目简介

**Rivet** 是一个现代化的跨平台文件管理应用，基于 Electron + React + TypeScript 构建，支持 SFTP 和 WebDAV 协议。

### 1.2 核心特性

| 特性         | 说明                    |
| ------------ | ----------------------- |
| 多协议支持   | SFTP 和 WebDAV          |
| 安全凭证管理 | Keytar 系统密钥链       |
| 现代化 UI    | React 19 + Tailwind CSS |
| 高性能渲染   | 虚拟列表技术            |
| 国际化       | i18next 多语言支持      |
| 严格安全     | 三层架构隔离            |

### 1.3 架构原则

1. **三层隔离**: Main ↔ Preload ↔ Renderer 严格分离
2. **单向通信**: 渲染进程通过 IPC 调用主进程
3. **类型安全**: 共享类型定义确保一致性
4. **安全第一**: Preload 只暴露必要 API

## 3. 整体架构

### 3.1 三层架构图

```
┌─────────────────────────────────────────────────────────┐
│                    RENDERER PROCESS                      │
│   React Components | Zustand Stores | User Interactions  │
└─────────────────────────┬───────────────────────────────┘
                         │ window.electronAPI
┌─────────────────────────▼───────────────────────────────┐
│                    PRELOAD SCRIPT                        │
│         Context Bridge | API Exposing | Validation       │
└─────────────────────────┬───────────────────────────────┘
                         │ IPC (invoke/handle)
┌─────────────────────────▼───────────────────────────────┐
│                    MAIN PROCESS                          │
│   Window Management | Protocol | Session | Credential   │
└─────────────────────────────────────────────────────────┘
```

### 3.2 进程职责

| 进程         | 职责       | 可用 API                 |
| ------------ | ---------- | ------------------------ |
| **Main**     | 系统级操作 | Node.js + Electron API   |
| **Preload**  | 安全桥接   | Context Bridge           |
| **Renderer** | UI 渲染    | 浏览器 API + electronAPI |

| 模块                              | 进程     | 职责                   |
| --------------------------------- | -------- | ---------------------- |
| `main/app`                        | Main     | 应用生命周期、窗口管理 |
| `main/ipc`                        | Main     | IPC 通信处理           |
| `main/services/protocol`          | Main     | SFTP/WebDAV 协议实现   |
| `main/services/SessionManager`    | Main     | 会话管理               |
| `main/services/CredentialManager` | Main     | 凭证管理               |
| `main/stores`                     | Main     | 配置持久化             |

| `renderer/components`             | Renderer | UI 组件                |
| `renderer/features`               | Renderer | 功能模块               |
| `renderer/stores`                 | Renderer | Zustand 状态管理       |
| `shared`                          | Both     | 共享类型和常量         |

## 9. 数据流

### 9.1 连接流程

```
用户点击连接
    ↓
ConnectionDialog → useConnectionStore.connect()
    ↓
window.electronAPI.protocol.connect()
    ↓
Preload → ipcRenderer.invoke()
    ↓
Main → ProtocolService.connect()
    ↓
获取密码 → 选择协议 → Protocol.connect()
    ↓
SessionManager.register()
    ↓
返回结果 → UI 更新
```

### 9.2 文件列表流程

```
用户导航目录
    ↓
useDirectoryNavigation.navigate()
    ↓
useFileOperations.list()
    ↓
electronAPI.protocol.list()
    ↓
Main → Protocol.list()
    ↓
SFTP/WebDAV 客户端执行
    ↓
返回 FileInfo[] → 更新状态 → 组件渲染
```

## 10. 安全设计

### 10.1 Context Isolation

```typescript
// BrowserWindow 配置
new BrowserWindow({
  webPreferences: {
    nodeIntegration: false,
    contextIsolation: true,
    sandbox: true,
    webSecurity: true,
  },
})
```

### 10.2 安全 API 暴露

- ✅ 显式白名单暴露
- ❌ 禁止通配暴露 ipcRenderer
- ✅ 输入验证在 IPC Handler 中进行

### 10.3 输入验证

每个 IPC Handler 都包含类型验证，确保传入参数的正确性。

## 11. 构建和打包

### 11.1 构建流程

```bash
npm run build
    ├─> vite build                    # 渲染进程
    ├─> vite build --config vite.preload.config.ts  # 预加载
    └─> tsc -p tsconfig.main.json     # 主进程
```

### 11.2 打包配置

使用 electron-builder 配置，支持 Windows (NSIS)、macOS (DMG)、Linux (AppImage)。
