## 2. 主进程模块

### 2.1 窗口工厂

[window-factory.ts](../src/main/app/window-factory.ts) - 负责创建无边框窗口和窗口生命周期管理。

**FramelessWindowOptions 类型定义**：

```typescript
interface FramelessWindowOptions {
  id: string // 窗口唯一标识
  route?: string // 渲染进程路由路径
  title?: string // 窗口标题
  width?: number // 宽度（默认 1200）
  height?: number // 高度（默认 800）
  minWidth?: number // 最小宽度（默认 800）
  minHeight?: number // 最小高度（默认 600）
  parent?: BrowserWindow // 父窗口（模态对话框）
  modal?: boolean // 是否模态
  alwaysOnTop?: boolean // 是否置顶
  resizable?: boolean // 是否可调整大小
  show?: boolean // 是否立即显示（默认 false）
}
```

**平台差异处理**：

| 平台    | frame   | titleBarStyle | 说明               |
| ------- | ------- | ------------- | ------------------ |
| macOS   | `true`  | `'hidden'`    | 保留系统交通灯按钮 |
| Windows | `false` | `'default'`   | 完全由 React 接管  |
| Linux   | `false` | `'default'`   | 完全由 React 接管  |

**窗口状态事件转发**：

主进程监听窗口最大化/还原事件，通过 IPC 发送给渲染进程：

```typescript
win.on('maximize', () => {
  win.webContents.send('window-state-changed', {
    windowId: options.id,
    isMaximized: true,
  })
})
```

## 3. Preload 脚本

### 3.1 Preload 入口

[index.ts](../src/preload/index.ts) - 统一暴露所有 API 到渲染进程。

**安全原则**：

- 仅通过 contextBridge 暴露白名单 API
- 禁止直接暴露 ipcRenderer 对象
- 所有通信使用 send/invoke/on 的包装器

```typescript
contextBridge.exposeInMainWorld('electronAPI', {
  protocol: protocolAPI,
  config: configAPI,
  dialog: dialogAPI,
  hostKey: hostKeyAPI,
  system: systemAPI,
  utils: utilsAPI,
  window: windowAPI,
  windowMeta: windowAPI.getMeta(),
  refreshWindowMeta: windowAPI.refreshMeta,
})
```

**API 清单**：

| API 模块            | 说明                                   |
| ------------------- | -------------------------------------- |
| `protocol`          | 文件操作（连接、列表、删除、重命名等） |
| `config`            | 配置存储（键值对）                     |
| `dialog`            | 系统对话框（打开/保存文件）            |
| `hostKey`           | SSH 主机密钥管理                       |
| `system`            | 系统信息（临时目录、下载目录）         |
| `utils`             | 工具函数（UUID、密码加密）             |
| `window`            | 窗口控制（最小化、最大化、关闭）       |
| `windowMeta`        | 当前窗口元数据 `{ windowId, route }`   |
| `refreshWindowMeta` | 刷新窗口元数据                         |

### 3.2 窗口控制 API

[window.preload.ts](../src/preload/window.preload.ts) - 窗口控制 API 实现。

```typescript
export const windowAPI = {
  minimize: (): void => {
    ipcRenderer.send('window-minimize')
  },

  maximize: (): void => {
    ipcRenderer.send('window-maximize')
  },

  close: (): void => {
    ipcRenderer.send('window-close')
  },

  getState: (): Promise<{ isMaximized: boolean; platform: string }> => {
    return ipcRenderer.invoke('window-get-state')
  },

  onStateChange: (callback: (state: { isMaximized: boolean }) => void): (() => void) => {
    const handler = (_: IpcRendererEvent, state: { isMaximized: boolean }) => {
      callback(state)
    }
    return listenerManager.on('window-state-changed', handler)
  },

  createChild: (options: {
    id: string
    route: string
    width?: number
    height?: number
    title?: string
  }): Promise<string> => {
    return ipcRenderer.invoke('window-create', options)
  },

  closeChild: (id: string): Promise<boolean> => {
    return ipcRenderer.invoke('window-close-by-id', id)
  },

  getMeta: (): { windowId: string; route: string } => {
    const hash = window.location.hash.replace('#', '')
    return {
      windowId: 'main',
      route: hash || '/',
    }
  },

  refreshMeta: async (): Promise<{ windowId: string; route: string }> => {
    return (await ipcRenderer.invoke('get-window-meta')) as { windowId: string; route: string }
  },
}
```

**API 列表**：

| 方法                      | 说明               | 返回值                               |
| ------------------------- | ------------------ | ------------------------------------ |
| `minimize()`              | 最小化窗口         | `void`                               |
| `maximize()`              | 最大化/还原窗口    | `void`                               |
| `close()`                 | 关闭窗口           | `void`                               |
| `getState()`              | 获取窗口状态       | `Promise<{ isMaximized, platform }>` |
| `onStateChange(callback)` | 监听窗口状态变化   | `() => void` (取消订阅)              |
| `createChild(options)`    | 创建子窗口         | `Promise<string>` (窗口 ID)          |
| `closeChild(id)`          | 关闭子窗口         | `Promise<boolean>`                   |
| `getMeta()`               | 获取当前窗口元数据 | `{ windowId, route }`                |
| `refreshMeta()`           | 刷新窗口元数据     | `Promise<{ windowId, route }>`       |

### 3.3 事件监听管理

[listener-manager.ts](../src/preload/listener-manager.ts) - 统一管理 IPC 事件订阅，防止内存泄漏。

```typescript
class ListenerManager {
  on<T extends unknown[]>(
    channel: string,
    handler: (event: IpcRendererEvent, ...args: T) => void
  ): () => void {
    // 注册事件监听，返回取消订阅函数
  }

  cleanup(): void {
    // 清理所有监听器
  }
}

window.addEventListener('beforeunload', () => {
  listenerManager.cleanup()
})
```

**特性**：

- 自动追踪所有注册的监听器
- 页面卸载时自动清理
- 返回取消订阅函数，支持手动清理

## 4. 渲染进程组件

### 4.1 TitleBar 组件

[TitleBar.tsx](../src/renderer/components/common/TitleBar.tsx) - 跨平台无边框窗口标题栏。

**特性**：

- 自动识别平台（macOS / Windows / Linux）
- macOS: 仅显示占位条，系统交通灯自动渲染
- Windows/Linux: 完整自定义按钮（最小化/最大化/关闭）
- 支持 `childMode`: 子窗口隐藏最大化按钮，仅显示关闭
- 支持自定义中间内容和左侧内容
- 支持主题切换（通过 CSS 变量）

**Props 定义**：

```typescript
interface TitleBarProps {
  childMode?: boolean // 子窗口模式
  centerContent?: React.ReactNode // 中间区域自定义内容
  leftContent?: React.ReactNode // 左侧额外内容
  title?: string // 自定义标题文字
}
```

**初始化流程**：

```typescript
useEffect(() => {
  const init = async () => {
    const state = await window.electronAPI.window.getState()
    setIsMaximized(state.isMaximized)
    setPlatform(state.platform)

    unsubscribe = window.electronAPI.window.onStateChange(newState => {
      setIsMaximized(newState.isMaximized)
    })
  }

  void init()
  return () => unsubscribe?.()
}, [])
```

| `.draggable`     | 使元素成为窗口拖拽区域                         |

**使用示例**：

## 8. FAQ

### Q1: 标题栏按钮点击无反应？

**排查步骤**：

1. 按钮元素是否有 `no-drag` class？
2. Preload 是否正确暴露 `window` API？
3. 主进程 IPC 处理器是否已注册？
4. 检查日志文件是否有错误信息。

### Q2: 子窗口的 `id` 重复会怎样？

WindowManager 会检测到已存在的窗口并执行 `focus()`，不会重复创建。

### Q3: 开发时 Vite HMR 导致 `window.electronAPI` 丢失？

Electron 的 Preload 只在窗口加载时注入一次。刷新整个窗口（Ctrl+R / Cmd+R）即可恢复。

### Q4: macOS 交通灯按钮位置不对？

调整 `trafficLightPosition` 参数（在 window-factory.ts 中配置）。

### Q5: 如何在渲染进程中使用日志？

```typescript
import logger from '@renderer/utils/logger.js'

logger.info('信息日志')
logger.warn('警告日志')
logger.error('错误日志', error)
logger.debug('调试日志')
```

**日志文件位置**：`{userData}/logs/main.log`
