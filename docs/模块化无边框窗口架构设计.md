## 2. 主进程：窗口工厂模块

### 2.1 文件：`src/main/app/window-factory.ts`

**核心功能**：统一创建无边框窗口，自动处理平台差异。

#### 2.1.1 类型定义

```typescript
export interface FramelessWindowOptions {
  id: string // 窗口唯一标识
  route?: string // 渲染进程路由路径
  title?: string // 窗口标题
  width?: number // 宽度（默认 1200）
  height?: number // 高度（默认 800）
  minWidth?: number // 最小宽度（默认 800）
  minHeight?: number // 最小高度（默认 600）
  parent?: BrowserWindow // 父窗口（模态对话框）
  modal?: boolean // 是否模态
  alwaysOnTop?: boolean // 是否置顶
  resizable?: boolean // 是否可调整大小
  show?: boolean // 是否立即显示（默认 false）
}
```

#### 2.1.2 平台差异处理

| 平台    | frame   | titleBarStyle | 说明               |
| ------- | ------- | ------------- | ------------------ |
| macOS   | `true`  | `'hidden'`    | 保留系统交通灯按钮 |
| Windows | `false` | `'default'`   | 完全由 React 接管  |
| Linux   | `false` | `'default'`   | 完全由 React 接管  |

**核心配置代码**：

```typescript
const isMac = process.platform === 'darwin'

const browserOptions: BrowserWindowConstructorOptions = {
  width: options.width ?? 1200,
  height: options.height ?? 800,
  minWidth: options.minWidth ?? 800,
  minHeight: options.minHeight ?? 600,
  title: options.title ?? 'Rivet',

  // 无边框核心配置
  titleBarStyle: isMac ? 'hidden' : 'default',
  frame: isMac,
  ...(isMac ? { trafficLightPosition: { x: 16, y: 14 } } : {}),

  webPreferences: {
    preload: path.join(__dirname, '../preload/index.cjs'),
    contextIsolation: true,
    nodeIntegration: false,
    sandbox: true,
  },
}
```

#### 2.1.3 窗口状态事件转发

```typescript
win.on('maximize', () => {
  if (!win.isDestroyed()) {
    win.webContents.send('window-state-changed', {
      windowId: options.id,
      isMaximized: true,
    })
  }
})

win.on('unmaximize', () => {
  if (!win.isDestroyed()) {
    win.webContents.send('window-state-changed', {
      windowId: options.id,
      isMaximized: false,
    })
  }
})
```

#### 2.1.4 WindowManager API

| 方法                          | 说明                       |
| ----------------------------- | -------------------------- |
| `create(options)`             | 创建并注册窗口（防止重复） |
| `get(id)`                     | 通过 ID 获取窗口           |
| `close(id)`                   | 通过 ID 关闭窗口           |
| `getAll()`                    | 获取所有存活窗口           |
| `broadcast(channel, ...args)` | 向所有窗口广播消息         |

**窗口防重复创建逻辑**：

```typescript
create(options: FramelessWindowOptions): BrowserWindow {
const existing = windowMap.get(options.id)
if (existing && !existing.isDestroyed()) {
    existing.focus()
    return existing
}

const win = createFramelessWindow(options)
windowMap.set(options.id, win)

registerWindowMeta(win, options.id, options.route ?? '/')

win.on('closed', () => {
    windowMap.delete(options.id)
    unregisterWindowMeta(win)
})

return win
}
```

## 3. 主进程入口

### 3.1 文件：`src/main/app/main.ts`

**职责**：注册窗口控制 IPC 处理器，创建主窗口，管理窗口元数据。

#### 3.1.1 窗口元数据管理

使用 WeakMap 存储窗口元数据（解决 sandbox 模式下 `process.argv` 不可用问题）：

```typescript
const windowMetaMap = new WeakMap<BrowserWindow, { windowId: string; route: string }>()

export function registerWindowMeta(win: BrowserWindow, id: string, route: string): void {
  windowMetaMap.set(win, { windowId: id, route })
}

ipcMain.handle('get-window-meta', event => {
  const win = BrowserWindow.fromWebContents(event.sender)
  if (!win) return { windowId: 'unknown', route: '/' }
  return windowMetaMap.get(win) ?? { windowId: 'unknown', route: '/' }
})
```

#### 3.1.2 窗口控制 IPC

```typescript
ipcMain.on('window-minimize', event => {
  const win = BrowserWindow.fromWebContents(event.sender)
  win?.minimize()
})

ipcMain.on('window-maximize', event => {
  const win = BrowserWindow.fromWebContents(event.sender)
  if (win?.isMaximized()) {
    win.unmaximize()
  } else {
    win?.maximize()
  }
})

ipcMain.on('window-close', event => {
  const win = BrowserWindow.fromWebContents(event.sender)
  win?.close()
})

ipcMain.handle('window-get-state', event => {
  const win = BrowserWindow.fromWebContents(event.sender)
  return {
    isMaximized: win?.isMaximized() ?? false,
    platform: process.platform,
  }
})
```

#### 3.1.3 子窗口管理 IPC

```typescript
ipcMain.handle(
  'window-create',
  (
    _event,
    options: { id: string; route: string; width?: number; height?: number; title?: string }
  ) => {
    WindowManager.create({
      ...options,
      width: options.width ?? 800,
      height: options.height ?? 600,
    })
    return options.id
  }
)

ipcMain.handle('window-close-by-id', (_event, id: string) => {
  WindowManager.close(id)
  return true
})
```

#### 3.1.4 创建主窗口

```typescript

  id: MAIN_WINDOW_ID,
  route: '/',
  width: 1000,
  height: 700,
  minWidth: 800,
  minHeight: 600,
  title: 'Rivet',
})
```

## 4. Preload 脚本

### 4.1 文件：`src/main/preload/index.ts`

**安全原则**：仅通过 `contextBridge` 暴露白名单 API。

#### 4.1.1 windowControl API

```typescript
const windowControl = {
  minimize: () => ipcRenderer.send('window-minimize'),
  maximize: () => ipcRenderer.send('window-maximize'),
  close: () => ipcRenderer.send('window-close'),
  getState: () => ipcRenderer.invoke('window-get-state'),
  onStateChange: callback => {
    const handler = (_: IpcRendererEvent, state) => callback(state)
    ipcRenderer.on('window-state-changed', handler)
    return () => ipcRenderer.removeListener('window-state-changed', handler)
  },
  createChild: options => ipcRenderer.invoke('window-create', options),
  closeChild: id => ipcRenderer.invoke('window-close-by-id', id),
}
```

#### 4.1.2 暴露到全局

```typescript
contextBridge.exposeInMainWorld('electronAPI', {
  windowControl,
  // ...其他 API
})
```

## 5. 标题栏组件

### 5.1 文件：`src/renderer/components/common/TitleBar.tsx`

**特性**：

- 自动识别平台（macOS / Windows / Linux）
- 支持 `childMode`：子窗口隐藏最小化/最大化按钮，仅显示关闭
- 支持自定义中间内容和左侧内容
- 零外部图标依赖（内联 SVG）
- 响应主题切换（通过 CSS 变量）

#### 5.1.1 Props 定义

```typescript
export interface TitleBarProps {
  /** 子窗口模式：隐藏最小化/最大化，仅显示关闭按钮 */
  childMode?: boolean
  /** 中间区域自定义内容（如标签页、搜索框） */
  centerContent?: React.ReactNode
  /** 左侧额外内容（在 Logo/标题之后） */
  leftContent?: React.ReactNode
  /** 自定义标题文字（默认 'Rivet'） */
  title?: string
}
```

#### 5.1.2 平台判断逻辑

```typescript
const [isMaximized, setIsMaximized] = useState(false)
const [platform, setPlatform] = useState<string>('win32')

useEffect(() => {
const init = async () => {
    const state = await window.electronAPI.windowControl.getState()
    if (state) {
    setIsMaximized(typeof state.isMaximized === 'boolean' ? state.isMaximized : false)
    setPlatform(typeof state.platform === 'string' ? state.platform : 'win32')
    }

    const unsubscribe = window.electronAPI.windowControl.onStateChange(
    (newState: { isMaximized: boolean }) => {
        setIsMaximized(newState.isMaximized)
    }
    )
    return unsubscribe
}, [])

const isMac = platform === 'darwin'
```

#### 5.1.3 macOS 标题栏

```tsx
if (isMac) {
  return (
    <header className="h-9 bg-bg border-b border-border flex items-center justify-center draggable titlebar-text shrink-0">
      <span className="text-xs text-text-muted font-medium tracking-wide">{title}</span>
    </header>
  )
}
```

#### 5.1.4 Windows/Linux 标题栏

```tsx
<header className="h-9 bg-bg border-b border-border flex items-center justify-between shrink-0">
  {/* 左侧：拖拽区 + Logo + 标题 */}
  <div
    className="flex-1 flex items-center h-full px-3 draggable titlebar-text"
    onDoubleClick={childMode ? undefined : handleMaximize}
  >
    <div className="flex items-center gap-2 no-drag">
      <AppLogo />
      <span className="text-sm text-text font-semibold">{title}</span>
      {leftContent}
    </div>
  </div>

  {/* 右侧：控制按钮 */}
  <div className="flex h-full items-center gap-1 px-2 no-drag">
    {centerContent}
    {!childMode && (
      <>
        <button onClick={handleMinimize} aria-label="Minimize">
          <IconMinus />
        </button>
        <button onClick={handleMaximize} aria-label={isMaximized ? 'Restore' : 'Maximize'}>
          {isMaximized ? <IconMaximize2 /> : <IconSquare />}
        </button>

    <button onClick={handleClose} aria-label="Close">
      <IconX />
    </button>
```

## 10. FAQ

### Q1: 标题栏按钮点击无反应？

**排查步骤**：

1. 按钮元素是否有 `no-drag` class？
2. Preload 是否正确暴露 `windowControl` API？
3. 主进程 IPC 处理器是否已注册？
4. 检查控制台是否有错误日志。

### Q2: 子窗口的 `id` 重复会怎样？

WindowManager 会检测到已存在的窗口并执行 `focus()`，不会重复创建。

### Q3: 开发时 Vite HMR 导致 `window.electronAPI` 丢失？

Electron 的 Preload 只在窗口加载时注入一次。刷新整个窗口（Ctrl+R / Cmd+R）即可恢复。

### Q4: macOS 交通灯按钮位置不对？

调整 `trafficLightPosition` 参数：

```typescript
trafficLightPosition: { x: 16, y: 14 }
```
